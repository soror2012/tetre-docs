# UI Style

![The title screen: night-blue sky, a Grand Cross skyline, an airship and a gold cross-diamond above the TETRE wordmark](/img/int-title.png)

## Windows

- Fill: deep violet at about 92% opacity.
- A 1 px cream inner border, gold corner studs and an ink outer edge.

## Text

- An **original pixel bitmap font**, drawn in code. Crisp at every scale and not a stock typeface.
- Body text in pale cream, speaker names in gold, emphasis in bloom pink.

## Title screen

A night-blue sky gradient, a silhouetted Grand Cross skyline with its clock tower and a rail bridge, an airship, a faint Ward lattice shimmering across the sky and the **TETRE** wordmark in a custom pixel display face above a gold cross-diamond.

## This site

The documentation theme follows the same rules. Light mode is cream stone with violet and gold. Dark mode is deep violet and ink. Headings use a pixel display face. Body text stays in a readable sans-serif.

## Display

| Setting | Value |
|---|---|
| Internal resolution | 480 x 270 (16:9) |
| Scaling | Integer scale preferred, nearest-neighbor, letterboxed on odd aspect ratios |
| Tile size | 16 px |
| Fullscreen | F key or the title menu |
